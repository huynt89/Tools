# Tiện Ích Mỗi Ngày

Trang web tĩnh gồm các công cụ tính toán đơn giản, có giao diện dùng được trên điện thoại và máy tính:

- **Tính điểm & xếp loại** — tính điểm trung bình môn theo hệ số đánh giá và tham khảo tiêu chí kết quả học tập tại Thông tư 22/2021/TT-BGDĐT.
- **Tính lương cá nhân** — ước tính lương theo ngày công, phụ cấp và tiền làm thêm giờ.
- Hai vị trí công cụ tiếp theo hiện được đánh dấu **Sắp ra mắt** trên trang chủ.

## Chạy trên GitHub Pages

1. Đẩy các tệp trong repository lên GitHub.
2. Mở **Settings → Pages** của repository.
3. Chọn nhánh cần xuất bản và thư mục gốc (`/root`), sau đó lưu.
4. Truy cập URL GitHub Pages được hiển thị trong phần Pages.

Trang dùng HTML, CSS và JavaScript thuần; không cần cài đặt hoặc build. Các liên kết và tài nguyên dùng đường dẫn tương đối để hỗ trợ cả GitHub Pages ở tên miền gốc lẫn URL dạng `/ten-repository/`.

## Lưu ý

Các kết quả là ước tính/tham khảo, không thay thế kết quả chính thức của nhà trường, bảng lương hoặc tư vấn chuyên môn. Công cụ tính lương chưa trừ thuế, bảo hiểm và các khoản khấu trừ; cách tính thực tế phụ thuộc hợp đồng và quy định áp dụng.
